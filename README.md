# 💳 Financial Health Index (FHI) Forecasting Model

> **Machine Learning Socio-Economic & Business Financial Health Prediction**

Predictive machine learning models for forecasting the Financial Health Index (FHI) using socio-economic indicators, trade commodities, export/import activity, firm size, and demographic spatial data.

---

## 🌟 Features
- Socio-economic dataset feature engineering.
- Predictive regression and ensemble modeling.
- Geographical & firm-size financial stability analytics.

---

## 🚀 Quick Start

```bash
git clone https://github.com/subu53/dataorg-financial-health-prediction.git
cd dataorg-financial-health-prediction

python main.py
```
